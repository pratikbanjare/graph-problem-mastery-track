# Stepwise guide to use the repository for learning Graph algorithms 

___

## Chapter 1: Understand Graphs

Start with [Chapter 1: Understand Graphs](chapter/chapter-1-understand-graph.md) to
learn graph terminology, directed and undirected graphs, weighted edges, and
common graph representations. The chapter also explains how these concepts map
to `Graph.java` and provides a Cucumber BDD exercise to validate the
implementation.
