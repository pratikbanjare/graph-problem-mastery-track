# Graph Problem Mastery Track

A chapter-by-chapter practice track for graph theory and graph algorithms. Work
through the lessons and exercises in this branch; you do not need to switch
branches between chapters.

## How to practice

1. Clone the repository and enter its directory:

   ```bash
   git clone https://github.com/pratikbanjare/graph-problem-mastery-track.git
   cd graph-problem-mastery-track
   ```

2. Start with Chapter 1 and follow the guides in order. Each guide introduces
   the topic, points to the implementation to work on, and explains the
   associated test.
3. Implement the chapter's task without changing its test scenarios, then run
   the test command provided in the guide. You can also run the full suite with
   `mvn test` (Java 17 and Maven required).
4. Continue to the next chapter on the same branch.
